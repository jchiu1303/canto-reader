Privacy
Everything stays on this device. The dictionary is bundled offline, there are no API keys, no accounts, no network requests, no analytics and no telemetry. Saved words live only in chrome.storage.local and are exported only when you click Export CSV. The extension is inert until you enable it on a tab via the toolbar button or Alt+Shift+C.
